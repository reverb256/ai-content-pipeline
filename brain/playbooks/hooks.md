# Hooks Playbook

> The first 1-2 lines decide whether anyone reads the rest. On X, the first
> tweet of a thread is the only one distributed to non-followers. The hook is
> the whole game.

## Hook Principles (X 2026)

1. **Front-load value in the first 70-90 characters.** That is the "Show more"
   cutoff on mobile.
2. **Concrete numbers beat adjectives.** "I spent $50k on X" > "I spent a lot".
3. **Specific first-person experience signals authority.** "I migrated 4 hosts
   off NixOS" is a proof statement, not a claim.
4. **Curiosity gap + promise + format hint.** The reader knows what they get
   and why they should click.

## Hook Patterns That Work (for our voice)

| Pattern | Example shape |
|---------|--------------|
| **Concrete numbers** | "I cut my infra cost 60% by moving off NixOS. Here's what actually mattered." |
| **Contrarian claim** | "Most people are wrong about AI agents. The bottleneck isn't writing — it's the loop." |
| **Mistake confession** | "I spent 3 months building an agent fleet that produced nothing. Here's what was missing." |
| **Build sequence** | "I built a 6-bot media company. Day 1: the loop, not the drafts." |
| **Proof point** | "4 hosts, 1 weekend, 0 failed units. The migration playbook." |
| **Insider poll / aggregated authority** | "I asked 10 operators the same question. 8 gave the same answer." |

## Hook Anti-Patterns

- "Unpopular opinion:" / "Hot take:" — the algorithm discounts these openers
- Questions with no substance ("Thoughts?") — reply bait without value is
  penalized
- Vague promises ("This will change everything")
- Starting with "I think" / "Here's the thing" — weak openers
- Links in the main post (always first reply)

## Thread Structure (the high-value format)

1. **Tweet 1 — Hook.** Standalone value + curiosity + "a thread" signal. Must
   work alone — it is the only one most people see.
2. **Tweet 2 — Stakes.** Why this matters, who it affects, what happens if
   ignored.
3. **Tweets 3-5 — Substance.** One complete, valuable insight per tweet. No
   teasers — the full point, so readers who stop at 3 still got value.
4. **Tweet 6 — Surprise.** An insight that contradicts the intuitive
   conclusion. This is what generates replies.
5. **Tweet 7 — Payoff CTA.** Summary + soft call to action (follow, bookmark,
   reply). Never a hard sell.

## Thread Rules

- 7-12 tweets is the sweet spot (dropout rises after 10-12)
- Each tweet under 240 chars; generous line breaks
- One idea per tweet
- Post the whole thread in one session
- Reply to your own thread with a question to seed conversation

## The One-Line Test

Every hook must pass: "Would someone bookmark this to use later?" If no —
it is a reply, not a standalone post.
