# Performance Playbook

> Content analytics that stop at reporting numbers are a dashboard. A useful
> learning system changes how the next campaign is built. This is the loop
> closing.

## What We Record After Each Campaign

```
signal and subject:
reader outcome:
central angle:
hook type:
format:
platform:
impressions / reach:
meaningful engagement:
clicks, follows, replies, or conversions tied to the goal:
what the editor approved or revised:
what should be tested again:
```

## The Weekly Review (editor runs it)

Compare recent campaigns and propose changes to the playbooks. The proposal
must name the posts supporting it. One strong result creates a hypothesis,
not a universal rule.

The weekly review returns three lists:

1. **Keep** — patterns that worked repeatedly and still match the strategy
2. **Test** — promising patterns that need another controlled attempt
3. **Stop** — repeatedly weak patterns, duplicated formats, expensive work
   with no useful result

j_kro approves the changes before the brain updates.

## X Signals That Matter (2026)

| Signal | What it means | Weight |
|--------|--------------|--------|
| Replies | Conversation; algorithm's strongest signal | Highest |
| Bookmarks | "I'll return to this" — quality signal | High |
| Reposts | Spread | High |
| Profile clicks | Interest | Medium |
| Likes | Weak — barely moves the needle | Low |

**Rule:** a tweet that earns 50 likes + 20 bookmarks beats 200 likes + 0
bookmarks. Every tweet should earn at least one bookmark from someone new.

## Feedback → Playbook Mapping

| Signal | Updates |
|--------|---------|
| Hook engagement (first 60 min) | hooks.md |
| Thread completion | threads structure in hooks.md |
| Bookmark rate | topic selection, depth, reusable objects |
| Reply quality | angles.md, tension selection |
| Platform conversion | platforms.md per-platform rules |
| Editor revisions | RULINGS.md (new rulings) |

## Autonomy Boundary

Performance data → proposed playbook changes → **human approves** → brain
updates. The system proposes; the human disposes. This is how taste
compounds without the human repeating themselves.
