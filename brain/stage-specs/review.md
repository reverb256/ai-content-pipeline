# Stage Spec — Review (meticulous contract v1, 2026-09-02)

> Follows brain/QUALITY_DOCTRINE.md. SPEC + MECHANICAL GATE + SCORED REVIEW.
> Review is the critic pass. The reviewer judges the artifact against its
> stage spec's DONE WHEN + QUALITY_DOCTRINE. PASS advances. FAIL keeps the
> card at the same stage with specific critique — no advance.

## STAGE
review

## BOT
editor (default/SPOC)

## INPUT (read before reviewing)
- The artifact to review (path from the kanban card or stage spec).
- The stage spec for that artifact (`brain/stage-specs/<stage>.md`) — the
  reviewer MUST read the same spec the producer read.
- The kanban card comment from the producing stage (contains the gate result).
- `brain/QUALITY_DOCTRINE.md` + `brain/RULINGS.md` + `brain/voice.md`.
- `campaigns/<name>/research.md` (to verify evidence integrity downstream).

## OUTPUT (write these)
- Kanban comment on the card: PASS or FAIL + scored rubric + specific critique.
- If FAIL: the card stays at the producing stage (no advance). The critique
  names the exact section + the exact fix.

## SPEC (measurable — what the reviewer judges)

### 1. Spec compliance (DONE WHEN)
- Verify EVERY condition in the stage spec's DONE WHEN is satisfied.
- A reviewer may NOT pass an artifact that fails its own DONE WHEN.

### 2. Originality (anti-slideshow / anti-template)
- The artifact must NOT be template-slop. YouTube's inauthentic-content
  policy targets repetitive, low-effort template content.
- Scripts: hook is unique, not "In this video we're going to..."
- Visuals: beats are distinct, not the same stock clip rotated.
- Voice: delivery matches the script's emotive cues, not flat monotony.
- Score 1 any artifact that could be generated by feeding the same prompt
  into any other channel.

### 3. Voice / brain match
- Tone matches `brain/voice.md`. Stance matches. No off-brand language.
- Audience matches `brain/audience.md`. The artifact speaks TO them, not
  past them.

### 4. Evidence integrity
- Every consequential claim in the artifact traces to `research.md`.
- No invented numbers, quotes, or sources downstream of research.
- If research.md has 3 claims and the script makes 5, the 2 extra must
  be flagged.

### 5. QUALITY_DOCTRINE alignment
- The stage's mechanical gate was run (see MECHANICAL GATE below).
- The artifact would pass the mechanical gate if re-run now.

## MECHANICAL GATE (BLOCKS — reviewer runs BEFORE scoring)
The reviewer verifies two things:
1. **Artifact exists.** The file at the path the producer reported is
   non-empty and readable.
2. **The producing stage's mechanical gate was run.** The kanban comment
   from the producer MUST contain the gate result (PASS + measured values).
   - If the comment is missing the gate result → reviewer returns the task
     to the producer: "run your mechanical gate and report the result."
   - If the gate result is FAIL → reviewer does NOT score. A review that
     passes an artifact whose mechanical gate failed = REVIEWER ERROR.
     Return the task: "gate failed, fix first."

This gate is the reviewer's primary defense against "the bot said PASS
and shipped anyway." The reviewer is accountable for verifying the gate.

## SCORED REVIEW (1-10, min pass 7)
1. **Originality** — not template-slop; per-video variation present;
   inauthentic-content risk low.
2. **Spec compliance** — DONE WHEN conditions satisfied; mechanical gate
   verified.
3. **Audience value** — the target audience would find this useful /
   surprising / worth finishing.
4. **Evidence integrity** — every claim traces; nothing fabricated.
5. **Voice/brain match** — sounds like us, not like generic AI content.
6. **Technical quality** — format-specific standards met (audio clean,
   video not truncated, word counts met).
7. **Overall** — would you publish this, or is it filler?

PASS: all ≥ 7, mechanical gate verified. FAIL: card stays at the producing
stage; critique names the exact section + the exact fix. Retry up to 2
times, then STOP and flag to human.

## DONE WHEN
- Artifact exists and is non-empty.
- Producing stage's mechanical gate confirmed PASSED (in comment).
- Scored rubric posted: all criteria ≥ 7 (PASS) or specific critique (FAIL).
- If FAIL: card NOT advanced. Producer reworks. Reviewer re-reviews.
- If FAIL twice in a row: escalate to human — do not loop.
