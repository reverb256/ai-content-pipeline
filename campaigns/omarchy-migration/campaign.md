# Campaign: The accidental Linux journey — from a wiped Windows box to a personal autonomous corporation

**Status:** angle (awaiting human approval)

## Signal

- **event:** September 2025, j_kro accidentally wiped his Windows 11 gaming PC
  (targeted an NVMe instead of the USB he meant to try Omarchy on). That
  accident became the entry to a year-long Linux journey: Omarchy → distro
  hop (CachyOS, Fedora, Bazzite) → NixOS (March 2026, learning phase) → back
  to Omarchy (August 2026) → building a personal autonomous corporation on
  top (Hermes agent fleet, memlawb memory, kanban production desk, CDP
  browser acting as the operator).
- **source:** X posts (x.com/reverb256 — retrospective, gaming posts,
  VRChat/FBT context), reverb256.ca (profile: 14 projects, 4-host NixOS
  cluster, "15 years food service, 20 years tech-curious"), GitHub
  (github.com/reverb256, 35 public repos), memlawb cluster facts (zephyr +
  nexus on Omarchy 4.0.0, 0 failed units, garage intact, YubiKey secrets)
- **urgency:** HIGH — the accident story is deeply relatable (everyone who has
  ever wiped a wrong disk knows the moment), the arc is novel (few people have
  gone Windows → Omarchy → NixOS → Omarchy → autonomous corporation in a
  year), and the current state is fresh and verifiable. Decay: the "I wiped my
  PC by accident" hook is evergreen; the migration specifics matter now.
- **audience question:** What happens when you accidentally wipe your Windows
  gaming PC? For me: a year of Linux chaos that ended with a personal
  autonomous corporation running on Omarchy.
- **authority clip / proof object:** the X retrospective thread (the arc),
